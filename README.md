## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/<k4rol4j>/restaurants-app.git
cd restaurants-app
```

### 2. Run the frontend

```bash
cd frontend-react
npm install     # only on the first run
npm run dev
```

### 3. Run the backend

Open a second terminal:

```bash
cd backend-nodejs
npm install        # only on the first run
npm run start:dev
```

### 4. Access the application

After starting both parts, go to:

🔗 http://localhost:5173
